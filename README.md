# CUTLINERS — Bespoke Raw Denim Atelier & Custom Clothing ✂️👖

Мобильно-ориентированный сайт-каталог мастерской индпошива **CUTLINERS** (джинсы из тяжелого японского сырого селвиджа, кастомные карпентеры, куртки и одежда ручной работы).

## ✨ Особенности
- **Mobile-First дизайн**: Полная оптимизация под смартфоны, крупные карточки лукбука, плавная нижняя навигация (Bottom Nav) и всплывающие карточки деталей (Bottom Sheets).
- **Мрачная аутентичная эстетика**: Тёмные тона, текстура портновского мела, деним, каллиграфический логотип **CUTLINERS** с завитками (*Pinyon Script*) и альтернативные готические шрифты.
- **Интерактивные сезонные темы**:
  - 🎃 **Halloween Drop**: Интерактивный перепуганный чёрный мультяшный кот на дыбах, тыквы со светящимся оскалом, шляпа ведьмы, конфеты Reese's и паутина.
  - ❄️ **Winter & New Year**: Заснеженные лапы елей, морозный иней, падающие снежинки.
  - 🥚 **Gothic Easter**: Обсидиановые резные яйца с золотой филигранью.
  - 🌅 **Summer Season**: Закат, неоновые пальмы, летний вайб.
  - 🖤 **Valentine Noir**: Черное пронзенное сердце, алая нить.
  - ✂️ **Raw Denim Atelier**: Классическая мастерская с портновской сантиметровой лентой.
- **Панель мастеров (Admin)**:
  - Добавление изделий с фотографиями (камера/галерея телефона).
  - Подробная таблица замеров (пояс, длина внешнего/шагового шва, посадка спереди/сзади, бедро, выход низа, плотность в oz).
  - Смена активной темы для всех посетителей.
  - Экспорт и импорт каталога в JSON для синхронизации между телефонами двух мастеров.
- **Интерактивный гайд по замерам**: Наглядная схема джинс с метками A-F для точного снятия мерок.
- **Быстрый заказ**: Кнопка прямой связи в Telegram с предзаполненными параметрами выбранной вещи и замерами.

## 🚀 Запуск и разработка

```bash
# Установка зависимостей
npm install

# Запуск локального сервера (доступен на ПК и телефоне по Wi-Fi)
npm run dev

# Сборка проекта для продакшена
npm run build
```
